# 決策紀錄

新的在上面。格式：日期・決定・理由・之後要不要再看。

## 2026-11-23 v0.3（回饋：圖片太簡陋、開頭的華語生硬）
- **圖片改成真實照片（使用者選擇）。** 小孩認得真實的樣子；不再受裝置 emoji 長相影響。來源 Openverse，只收 CC0、公有領域、CC BY、CC BY-SA；每個字取 8 張候選排成縮圖表，人工逐張挑選（主體清楚、單一、背景乾淨、沒有可辨識的人臉）。裁成正方形 384px WebP。作者與授權記在 `site/content/credits.json`，家長頁可查。
- **身體、玩具、衣服、家裡改用 3D 插圖（Fluent Emoji，MIT），不用照片。** 實際搜尋後發現：身體部位照片牽涉真人隱私，且結果常有不適合小孩的畫面；衣服、玩具照片多是穿著的人或商品廣告，robot 還出現受版權保護的卡通角色；家裡的浴缸也有不適合的畫面。同一單元統一風格。
- **太陽、星星、彩虹、雨、鯊魚、章魚、蝦子、魷魚也用 3D 插圖。** 太陽照片是逆光剪影、星星只是黑色夜空、彩虹太淡、雨只是水面漣漪、鯊魚照片太暗；章魚找不到、蝦子都是料理、搜 squid 得到花枝。4～5 歲認不出來的寧可用插圖。
- **每個字 8 張候選、成品再整體檢查一次。** 成品檢查時修正了獅子、乳牛的裁切（臉、頭被裁掉）與月亮的黑邊。
- **顏色、數字兩個單元不用照片。** 照片裡的東西（紅蘋果）會讓小孩以為在問物品；維持色塊與星星數量。
- **提示語全部改成英文（使用者選擇）。** 裝置華語語音生硬；全部用同一個自然英文聲音，整個遊戲是沉浸式英文。開頭說明改為 "Listen, and touch the picture!"，進單元說 "Let's go to the zoo!" 等。→ 若小孩一開始聽不懂，由大人示範一次。
- **家長頁可以連到照片原始來源。** 這是授權要求的出處標示；只有家長點了才會連外，遊戲本身仍不對外連線。

## 2026-11-23 v0.2（回饋：太陽春、口音生硬、單字太少）
- **英文改用預先產生的音檔（Kokoro-82M，af_heart 美式女聲）。** 瀏覽器內建語音生硬且各裝置不同；Kokoro 是 Apache-2.0，產生的音檔可以放在公開網站；預先產生也讓 iPad 播放穩定。模型與執行環境放在 `.tts/`，不進 git。
- **華語提示仍用裝置語音。** Kokoro 華語是中國口音，iPad 內建台灣華語較合適。→ v0.3 讓家長在裝置上自己錄。
- **音檔用 Web Audio 播放並全部預先快取。** iPad 上 Web Audio 在第一次點擊解鎖後可隨時播放，比 `<audio>` 穩；全部約數 MB，可完整離線。
- **詞彙擴充到 13 個單元、約 140 字；首頁改成地圖。** 單元＝一組主題詞彙；點單元直接開始，少一個步驟（4～5 歲）。
- **句子題只給熟練度 ≥2 的字。** 先認得單字，再在句子裡聽出來。
- **數字用星星數量表示、不用阿拉伯數字。** 4～5 歲不一定認得數字符號；練的是聽英文數字。
- **同一英文字在不同單元用不同 id（orange / c_orange）。** 音檔與進度以 id 區分。

## 2026-11-23 第一版
- **對象 4～5 歲。** 不識字，所以全部靠語音和圖；畫面文字只給大人看。
- **一回合 6 題、一開始 2 個選項。** 這個年齡專注時間短、選項多容易亂點；表現好再自動升到 3 個。
- **點錯不扣分、沒有計時、沒有分數。** 避免挫折。進步由家長頁看。
- **圖片先用 emoji。** 不需要畫圖或找授權就能先讓小孩試玩；`image` 欄位已預留換成圖檔。→ 小孩試玩確定玩法後再換。
- **語音先用瀏覽器內建（Web Speech API）。** 不用錄音就能先試玩；缺點是各裝置聲音不同。→ 正式版改用預先產生的音檔（要確認語音的授權可以公開散佈）。
- **沒有打包步驟、不用框架。** 檔案少、AI 和人都容易直接改；需要時再加 Vite。
- **進度只存在裝置上，提供匯出 / 匯入。** 不收資料，就不需要後端與隱私政策的負擔。
- **發布在 GitHub Pages（公開 repo）。** 免費、HTTPS、PWA 可用；因為公開，不放任何家人資料。
- **commit 用 GitHub 提供的 noreply email。** 公開 repo 的 commit 會顯示 email，避免外洩個人信箱。
- **注音、台語欄位先留空。** 這些要以教育部辭典核對過才填，不用猜的。
