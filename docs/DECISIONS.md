# 決策紀錄

新的在上面。格式：日期・決定・理由・之後要不要再看。

## 2026-11-23 第一版
- **對象 4～5 歲。** 不識字，所以全部靠語音和圖；畫面文字只給大人看。
- **一回合 6 題、一開始 2 個選項。** 這個年齡專注時間短、選項多容易亂點；表現好再自動升到 3 個。
- **點錯不扣分、沒有計時、沒有分數。** 避免挫折。進步由家長頁看。
- **圖片先用 emoji。** 不需要畫圖或找授權就能先讓小孩試玩；`image` 欄位已預留換成圖檔。→ 小孩試玩確定玩法後再換。
- **語音先用瀏覽器內建（Web Speech API）。** 不用錄音就能先試玩；缺點是各裝置聲音不同。→ 正式版改用預先產生的音檔（要確認語音的授權可以公開散佈）。
- **沒有打包步驟、不用框架。** 檔案少、AI 和人都容易直接改；需要時再加 Vite。
- **進度只存在裝置上，提供匯出 / 匯入。** 不收資料，就不需要後端與隱私政策的負擔。
- **發布在 GitHub Pages（公開 repo）。** 免費、HTTPS、PWA 可用；因為公開，不放任何家人資料。
- **commit 用 GitHub 提供的 noreply email。** 公開 repo 的 commit 會顯示 email，避免外洩個人信箱。
- **注音、台語欄位先留空。** 這些要以教育部辭典核對過才填，不用猜的。
