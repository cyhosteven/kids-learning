# 科目：英文單字

## 學習目標
聽到英文單字或短句，能點出對的圖。只練「聽」，不練讀、寫、說。

## 題目語音
- 單字題念單字；句子題念 items.csv 的 sentence 欄（It's a lion.）。
- 第一題前加一句華語說明：「聽聽看，哪一個是…」，之後每題只念英文。
- 點錯時：華語「再聽一次喔」→ 重念題目。
- 點對時：英文稱讚，隨機一句：Great job! / Good job! / Yay! / Well done! / You got it! / Awesome!
- 得到貼紙：You got a sticker! ＋ 那個字。

## 語音來源
- **英文：預先產生的音檔**（`site/audio/en/`），用 `tools/make_audio.py` 從 items.csv 產生：
  - 引擎：Kokoro-82M（Apache-2.0，產生的音檔可公開散佈），美式女聲 `af_heart`，語速略慢。
  - 每個字兩個檔：`<id>.mp3`（單字）、`<id>_s.mp3`（句子）；另有稱讚語與單元名稱。
  - 新增或修改字後要重新執行產生器（只會產生缺少或內容改變的檔）。
  - 音檔不存在或載入失敗：退回瀏覽器內建語音。
- **華語提示：裝置內建語音。** Kokoro 的華語是中國口音；iPad 內建的台灣華語語音（美佳）較合適。→ v0.3 考慮讓家長自己錄。

## 文字顯示
- 預設圖卡下**不顯示**英文字（4～5 歲不識字，顯示了反而分心）。
- 家長可在設定開啟「顯示英文字」。
