# 科目：英文單字

## 學習目標
聽到英文單字，能點出對的圖。只練「聽」，不練讀、寫、說。

## 題目
- 題目語音：英文單字本身，例如「lion」。語速偏慢（家長可調）。
- 第一題前加一句華語說明：「聽聽看，哪一個是…」，之後每題只念英文。
- 點錯時：華語「再聽一次喔」→ 重念英文。
- 點對時：英文稱讚，隨機一句：Great job! / Good job! / Yay! / Well done! / You got it!
  （稱讚語本身也是小孩會聽熟的英文）

## 文字顯示
- 預設圖卡下**不顯示**英文字（4～5 歲不識字，顯示了反而分心）。
- 家長可在設定開啟「顯示英文字」。

## 語音來源
- 第一版：瀏覽器內建語音（Web Speech API）。英文優先選美式女聲；華語優先選台灣華語。
- 找不到語音時：圖卡下強制顯示英文字，家長頁顯示「這台裝置沒有英文語音」。
- 正式版：改成預先錄好的音檔（見 DECISIONS.md）。
