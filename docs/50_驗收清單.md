# 驗收清單

## 小孩實測（最重要）
- [ ] 4～5 歲小孩不靠大人說明，能自己玩完一回合
- [ ] 小孩玩完會想再玩一回合
- [ ] 連續 5 天後，第一級 5 個字聽到都能點對

## 功能
- [ ] 一回合 6 題，結束得到一張貼紙，貼紙本裡變彩色
- [ ] 點錯：圖卡搖一下變淡、重播題目，不扣分
- [ ] 連續答對 6 題後改成 3 個選項；3 選項時錯 2 題以上，下一回合回到 2 個
- [ ] 答錯的字下一回合會優先出現
- [ ] 點貼紙本裡的彩色貼紙會念出英文
- [ ] 到達每天上限後出現「休息一下」，家長頁可以延長
- [ ] 家長鎖答錯回首頁；答對可進家長頁
- [ ] 匯出進度 → 全部重設 → 匯入，進度與貼紙恢復

## 網頁 / 裝置
- [ ] iPad Safari：點「開始玩」後，每題都有聲音
- [ ] 加到主畫面後全螢幕開啟，看不到網址列
- [ ] 開飛航模式，重新打開仍能玩
- [ ] 關掉分頁再開，進度和貼紙都還在
- [ ] 遊戲中兩指縮放、長按圖卡，不會放大也不會跳出選單
- [ ] 1024×768（平板橫式）與 390×844（手機直式）版面都不跑版
- [ ] 開發者工具的網路面板，沒有任何對外部網站的請求
- [ ] 正式網址（GitHub Pages）上以上各項都正常
- [ ] 發布新版後，首頁出現「有新版本」提示，點了會更新
