# 單元與詞彙

資料：`site/content/units.csv`（單元）與 `site/content/items.csv`（每個字一列）。程式不寫死任何單字。

選字原則：4～5 歲生活中常見、圖片一看就懂、英文好念。每個單元前 5 個是 level 1（最好分辨），依序引入。

## items.csv 欄位
| 欄位 | 說明 |
|---|---|
| id | 唯一代號，也是音檔檔名（同一個英文字在兩個單元時用不同 id，例如水果 `orange`、顏色 `c_orange`） |
| unit | 單元 id |
| level | 單元內的順序等級 1～3 |
| image | `emoji:🦁`、`color:#e53935`（色塊）、`count:3`（畫 3 顆星星）、`img:檔名`（content/images/ 下的圖） |
| 英文 | 單字題念的字 |
| sentence | 句子題念的句子（直接寫完整句子，不用程式組文法），例如 It's an elephant. / They're shoes. / This is my nose. |
| 華語 | 給家長看；之後注音國字科目也會用 |
| 注音、台語漢字、台羅 | 先留空，要以教育部辭典核對過才填 |

## 圖片
- 大多用 emoji（裝置字型畫出，不需授權）；顏色用色塊，數字用星星數量（4～5 歲還不一定認得阿拉伯數字）。
- emoji 在不同裝置長得不一樣；2020 年以後的 emoji（🪑 🪟 🪁 🦭）在 iOS 14 以前可能顯示不出來。

## 畫面風格
- 明亮溫暖、草地與天空背景；圖卡大、圓角、厚邊框。
- 吉祥物「獅寶」：原創的圓臉小獅子（程式畫的 SVG），出現在地圖、答對、得到貼紙時。
