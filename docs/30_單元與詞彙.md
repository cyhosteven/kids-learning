## items.csv 欄位
| 欄位 | 說明 |
|---|---|
| id | 唯一代號，也是音檔與照片檔名（同一個英文字在兩個單元時用不同 id，例如水果 `orange`、顏色 `c_orange`） |
| unit | 單元 id |
| level | 單元內的順序等級 1～3 |
| image | `emoji:🦁`、`color:#e53935`（色塊）、`count:3`（畫 3 顆星星）、`img:檔名`（content/images/ 下的圖） |
| 英文 | 單字題念的字 |
| sentence | 句子題念的句子（直接寫完整句子，不用程式組文法），例如 It's an elephant. / They're shoes. / This is my nose. |
| 華語 | 給家長看；之後注音國字科目也會用 |
| 注音、台語漢字、台羅 | 先留空，要以教育部辭典核對過才填 |

## 圖片
- 圖片都在 `site/content/images/<id>.webp`（384×384），用 `tools/pick_images.py` 產生：
  - **真實照片**（v0.3 起）：動物園、農場、水果、食物、交通工具、海洋、大自然的大部分。搜尋候選、人工挑選，結果記在 `tools/image_picks.json`（可指定裁切中心與放大）。
  - **3D 插圖**（Microsoft Fluent Emoji，MIT）：身體、玩具、衣服、家裡整個單元，以及太陽、星星、彩虹、雨、鯊魚、章魚、蝦子、魷魚。理由見 DECISIONS.md。清單在 `tools/pick_images.py` 的 FLUENT。
- 挑選原則：主體清楚、只有一個（或一組，如 grapes）、背景乾淨、顏色自然、不要有可辨識的人臉、不要恐怖或不適合小孩的畫面。
- 授權：只收 CC0、公有領域、CC BY、CC BY-SA；作者與授權在 `site/content/credits.json`，家長頁可查。
- 顏色用色塊、數字用星星數量（照片容易讓小孩以為在問物品；4～5 歲不一定認得阿拉伯數字）。
- 地圖的單元圖示仍用 emoji（只是按鈕，不是題目）。

## 畫面風格
- 明亮溫暖、草地與天空背景；圖卡大、圓角、厚邊框。
- 吉祥物「獅寶」：原創的圓臉小獅子（程式畫的 SVG），出現在地圖、答對、得到貼紙時。
