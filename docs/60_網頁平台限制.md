# 網頁平台限制與對策

| 問題 | 原因 | 對策（已實作） |
|---|---|---|
| 聲音不會自動播 | 瀏覽器要先有使用者點擊才能出聲 | 開始畫面一顆大按鈕「開始玩」，點了才解鎖語音與音效 |
| 進度可能不見 | localStorage 會被清除資料、無痕模式清掉；iPad Safari 對久未造訪的網站也可能清除 | 引導加到主畫面；家長頁可匯出 / 匯入進度 |
| 小孩誤觸 | 兩指縮放、長按選單、選取文字、下拉重新整理 | viewport 禁止縮放；CSS 關閉選取、長按選單、overscroll |
| 內建語音不穩 | 各裝置語音不同 | 全部改用預先產生的英文音檔；只有音檔載入失敗時才退回瀏覽器語音 |
| emoji 長相不同 | 由裝置字型畫出 | 題目圖片改用照片；只剩地圖按鈕用 emoji |
| 更新後仍是舊版 | service worker 快取 | 版本號寫在 `js/version.js`；偵測到新版時首頁顯示「有新版本，點這裡更新」 |
| 子路徑 | GitHub Pages 網站在 `/kids-learning/` 下 | 所有資源用相對路徑 |
| 語音辨識 | 支援不一、錄音可能送雲端 | 不做 |
